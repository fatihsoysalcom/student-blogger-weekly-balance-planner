# Student Blogger Weekly Balance Planner

This script helps student bloggers plan and balance their academic, blog, and personal tasks for a week. It demonstrates how to prioritize different types of commitments and visualize time allocation to ensure a healthy balance between studies and online presence.

## Language

`python`

## How to Run

Save the code as `weekly_balance.py`.
Then run from your terminal: `python weekly_balance.py`
